# Monzoid

Домашний учёт по фондам в виде Telegram Mini App. В одной базе может быть несколько участников, у базы есть администратор.

## Как считается

- **Свободные средства за месяц** = доходы − план расходов + корректировки ± переносы остатков между фондами и свободными − переводы во вклады − покупки активов (+ продажи) − расходы по активам без фонда.
- **Остаток фонда за месяц** = план − факт ± переносы. Он копится в фонде и не входит в свободные средства.
- **Деньги** = свободные средства + фонды. **Всего** = деньги + стоимость вкладов + стоимость активов.
- **Возврат** уменьшает факт по фонду. Он хранится как расход с отрицательной суммой и может быть привязан к покупке; возвраты не могут превысить её сумму.
- **Расход участника** копит долг базы перед ним. Выплата гасит долг и не считается новым расходом. Доход к человеку привязывается отдельно и на долг не влияет.
- **Месяцы** закрываются вручную и строго по порядку. Заново можно открыть только последний закрытый. Итоги нигде не хранятся: каждый раз считаются по операциям, поэтому правка в прошлом месяце сразу меняет и все следующие.
- **План текущего месяца входит в фонды по дням:** к N-му числу в фонде доля плана N / число дней месяца (в ноябре 1/30 в день, в октябре 1/31). Это видно в строке «сейчас» в «Капитале», в «в фонде» и «Плане расходов» на экране месяца («на сегодня / весь план»). В «Статистика → Фонды» столбец «сейчас» тоже по дням. Закрытый месяц всегда с полным планом. День берётся по часам телефона.

Суммы хранятся в тиынах (1 ₸ = 100), поэтому копейки из выписок не теряются.

## Выписки

Поддерживаются PDF из Kaspi Gold и Freedom Bank: их можно загрузить в приложении или прислать боту в личку. Файлы не сохраняются, в базу попадают только строки операций. Присланное боту ждёт, пока в приложении не нажмут «Обработать».

1. Разбор сверяется с итогами самого банка. Если суммы расходятся, на экране проверки появляется предупреждение.
2. Показываются все операции выписки. Сами помечаются как пропускаемые, с причиной в подсказке и в плашке над списком:
   - переводы между своими картами и покупка вместе с её отменой;
   - строки, которые уже были в прошлых выписках;
   - операции, уже учтённые «в обработке».
3. Операция «в обработке» считается той же, когда банк её проводит, если совпадают банк и продавец (банк может дописать хвост к названию) и дата в пределах 10 дней. Сумма должна совпадать с точностью ±2 цента (в других валютах столько же по курсу). Подойдёт и сумма, уже внесённая по этой записи вместе с объединённым возвратом. Если сумма другая, операция приходит как новая, с подсказкой проверить, не дубль ли. Отменённую банком операцию нужно удалить вручную.
4. Фонд берётся из истории этой базы. Для новых продавцов его предлагает Claude Haiku, если задан ключ.
5. В учёт попадает только то, что подтвердил человек; выписка отправляется целиком. Если её загрузил участник, его расходы копят долг базы перед ним; если администратор, расходы идут из общих денег.

В Anthropic уходят только названия продавцов из покупок и платежей, номера из них убираются. Переводы с именами людей не отправляются.

## Основная валюта и вклады

Основная валюта выбирается при создании базы и потом не меняется: пересчёта пока нет. Операции из выписки в другой валюте проводятся в основной по официальному курсу Нацбанка РК на дату операции (если его нет, по последнему), сумму можно поправить на экране проверки. Если банк списал часть в валюте и остаток в основной, это две строки, и каждая вносится отдельно.

Вклады это отдельная группа рядом с фондами и свободными средствами: в основной валюте, в другой валюте или в акциях. Перевод во вклад забирает деньги из свободных средств. Стоимость вклада это количество на конец месяца, умноженное на цену. Цена текущего месяца обновляется каждый день, а по его окончании фиксируется, поэтому рост курса виден в статистике как рост накоплений, а прошлые месяцы не меняются. Прошлые месяцы без цены заполняются настоящими данными: курсы Нацбанка РК и месячные цены закрытия Yahoo Finance. Если данных нет, берётся ближайшая более поздняя цена. Курсы (Нацбанк РК, все пары через тенге) и котировки (неофициальный адрес Yahoo Finance) обновляются при запуске и раз в сутки; в запросах уходят только тикеры. Если источник недоступен, остаются прошлые значения с их датой.

Акции покупаются и продаются по тикеру, количеству и цене за штуку: в валюте акции (сумма по курсу на дату сделки) или сразу в основной валюте. Для нового тикера вклад заводится сам. Если цена отличается от котировки больше чем в 3 раза, приложение просит подтвердить. В сделке можно поправить дату, количество и цену.

## Активы

Недвижимость и машины учитываются как активы. Покупка и продажа это сделки, а не доходы и расходы: деньги уходят из свободных средств и возвращаются в них. Стоимость актива берётся из последней оценки на конец месяца, без оценки она равна уплаченному; проданный актив стоит 0. Оценки не правятся, только добавляются или снимаются. Расходы по активу (агентские, нотариус, регистрация) можно внести без фонда: они списываются прямо из свободных.

## Фонды

- **Перенос остатка** между фондами или в свободные средства (и обратно) меняет остатки, но не факт трат.
- **Архив:** остаток фонда при архивации переносится в другой фонд или в свободные средства, план дальше не наследуется. Новый расход в архивный фонд внести нельзя, старые записи в нём править можно. Фонд можно вернуть из архива.
- **Личный фонд** участника задаётся явно, один на человека. Участник может скрыть его операции от других участников (администраторы видят всё); итоги от этого не меняются.

## Начисление участнику

К личному фонду участника можно включить начисление. С месяца включения сумма плана фонда сама записывается расходом, оплаченным участником: долг базы растёт, остаток фонда не копится. Запись следует за планом, пока месяц открыт, закрытые месяцы не меняются. Выключение снимает начисления открытых месяцев.

## Участники

- **Без аккаунта:** администратор может добавить участника без аккаунта. Войти он не может, но на него записываются доходы, расходы и выплаты. Позже его можно связать с настоящим человеком по одноразовой ссылке или выбрать из уже вступивших. Вся его история в этой базе переходит к этому человеку, отменить связь нельзя.
- **Выход из базы** возможен всегда, даже при долге (приложение предупреждает). Профиль остаётся в базе без аккаунта, с историей и долгом. Если человек вернётся по любому приглашению, он снова получит этот профиль. Единственный администратор при выходе передаёт права следующему участнику с аккаунтом; последний участник с аккаунтом выйти не может.
- **Уведомления** от бота включаются и выключаются отдельно для каждой базы.

## Блокировка базы и копии

Заблокированную базу можно только читать. Работают снятие блокировки, выход из базы и копии.

Копия базы приходит администраторам от бота файлом `.db.gz` по расписанию: по умолчанию раз в неделю. Включить, выключить и выбрать интервал можно в «База → Копии базы в Telegram», там же отправить копию себе сразу. В файле только эта база: чужих баз и их участников в нём нет.

## Удаление и журнал

Операции, выплаты, корректировки, участники и теги из базы не удаляются: запись получает отметку `inactive_at` с датой и временем в UTC и перестаёт показываться и участвовать в расчётах. Правка в открытом месяце перезаписывает запись без истории.

Закрытый месяц менять может только администратор, и только с согласием на пересчёт итогов. Любые добавления, правки и удаления операций, корректировок, переносов, сделок по вкладам и оценок активов попадают в «База → История изменений», и их можно отменить; сразу после сохранения внизу на несколько секунд появляется кнопка «Отменить». Отмена в закрытом месяце тоже пересчитывает итоги. Описание, комментарий и привязку возврата в закрытом месяце можно поправить без пересчёта. Правки плана закрытого месяца (через «Открыть месяц заново») в журнал не попадают.

## Доходы

Доходы вносит администратор. Доход можно привязать к участнику базы, в форме и на экране проверки выписки. По умолчанию это тот, кто вносит операцию или загрузил выписку. На долги участников это не влияет.

Источник дохода определяется по тегам. Тег «зп …» означает зарплату того, к кому привязан доход. Иначе источником считается самый частый тег из стоящих на доходе, а без тегов это «Без тега». По источникам строится раздел «Доходы» в статистике и фильтр в списке операций. Там же расходы можно отфильтровать по тому, кто платил: из общих денег или конкретный участник.

## Темп трат

В текущем месяце на отметках 25%, 50% и 75% срока траты фонда сравниваются с такой же долей лимита. Если их больше, на экране «Месяц» появляется предупреждение и прогноз, когда кончится лимит. Учитываются траты до дня отметки, поэтому вывод держится до следующей отметки. Сохранённые в фонде остатки прошлых месяцев не учитываются. Фонды с начислением участнику не проверяются. Галочка у фонда в «База» → «Фонды» выключает проверку.

## Теги

Теги ставятся на расходы, возвраты и доходы и не влияют на суммы. Можно выбрать существующий или ввести свой.

- **Выписка:** тег ставится сам, если у этого продавца он стоит хотя бы на 70% покупок (недавние весят больше; есть ещё правило для регулярных платежей с той же суммой). Остальные частые теги показываются подсказками. Для новых продавцов теги предлагает Claude Haiku. На экране проверки их можно убрать или заменить.
- **Ручная операция:** подставляются теги прошлой операции с тем же комментарием, частые теги фонда показываются первыми.

В закрытом месяце теги, как и саму операцию, меняет только администратор с согласием на пересчёт.

## Локальный запуск

Нужен Node.js 22.13 или новее (используется встроенный `node:sqlite`).

```bash
npm install
```

```bash
npm run build
```

В `.env` укажи `DEV_AUTH=1` и `OWNER_TELEGRAM_IDS=1`, затем:

```bash
npm start
```

Приложение откроется на http://localhost:3000/?devUser=1. Другой номер в `devUser` означает другого пользователя: так можно проверить форму участника.

## Проверки

```bash
npm test
```

```bash
npm run typecheck
```

Тесты на настоящих выписках запускаются, только если заданы пути `KASPI_PDF` и `FREEDOM_PDF`. Сами выписки в репозиторий не добавляются.

## Запуск в Telegram

Нужны VPS на Debian или Ubuntu и домен, направленный на этот сервер. Вместо своего домена подойдёт адрес вида `1-2-3-4.sslip.io`. Если порт 443 занят, передай скрипту настройки другой порт вторым аргументом и укажи его в адресе Mini App.

1. Создай бота в @BotFather и включи Main Mini App: `/mybots` → бот → Bot Settings → Configure Mini App, адрес `https://твой-домен`. Там же настрой кнопку меню. Приглашения работают через Main Mini App.
2. Скопируй на сервер `deploy/setup-server.sh` и запусти его от root, указав домен. Скрипт установит Node.js и Caddy (он сам выпускает HTTPS-сертификат).
3. Заполни `/opt/monzoid/.env` на сервере: токен, имя бота, ключ Anthropic и `OWNER_TELEGRAM_IDS` (свой Telegram ID). Новые люди входят только по приглашению. Базу может создать владелец, участник какой-либо базы или человек с одноразовым приглашением в сервис («Ещё» → «Пригласить в сервис», кнопка есть только у владельца).
4. Со своего компьютера выполни `bash deploy/deploy.sh root@сервер`. Этой же командой выкладываются обновления.

Сервис работает с `NODE_ENV=production`, поэтому вход без Telegram отключён. База лежит в `/var/lib/monzoid`. Раз в сутки туда же, в `backups/`, сохраняется копия. Когда копии вместе превышают 128 МБ, удаляются самые старые. Эти копии остаются на том же сервере, так что время от времени скачивай их к себе.
