# Monzoid

Домашний учёт по фондам в виде Telegram Mini App. В одной базе может быть несколько участников, у базы есть администратор.

## Как считается

- **Свободные средства за месяц** = доходы − план расходов (плюс корректировки, минус переводы во вклады).
- **Остаток фонда за месяц** = план − факт. Он копится в фонде и не входит в свободные средства.
- **Всего** = свободные средства + фонды + стоимость вкладов.
- **Возврат** уменьшает факт по фонду. Он хранится как расход с отрицательной суммой.
- **Расход участника** копит долг базы перед ним. Выплата гасит долг и не считается новым расходом.
- **Месяцы** закрываются строго по порядку. Заново можно открыть только последний закрытый.

Суммы хранятся в тиынах (1 ₸ = 100), поэтому копейки из выписок не теряются.

## Выписки

Поддерживаются PDF из Kaspi Gold и Freedom Bank. Файлы не сохраняются, в базу попадают только строки операций.

1. Разбор сверяется с итогами самого банка. Если суммы расходятся, на экране проверки появляется предупреждение.
2. Операции «в обработке» показываются для проверки. Когда банк проводит такую операцию с той же суммой и у того же продавца, она не вносится второй раз. Отменённую банком операцию нужно удалить вручную. Повторно загруженные строки не показываются.
3. Правила заранее помечают переводы между своими картами и отмены покупок как пропускаемые.
4. Фонд берётся из истории этой базы. Для новых продавцов его предлагает Claude Haiku, если задан ключ.
5. В учёт попадает только то, что подтвердил человек.

В Anthropic уходят только названия продавцов из покупок и платежей, номера из них убираются. Переводы с именами людей не отправляются.

## Основная валюта и копилки

Основная валюта выбирается при создании базы и потом не меняется: пересчёта пока нет. Операции из выписки в другой валюте проводятся в основной по официальному курсу Нацбанка РК на дату операции (если его нет, по последнему), сумму можно поправить на экране проверки. Если банк списал часть в валюте и остаток в основной, это две строки, и каждая вносится отдельно.

Вклады это отдельная группа рядом с фондами и свободными средствами: в основной валюте, в другой валюте или в акциях. Перевод во вклад забирает деньги из свободных средств. Стоимость вклада это количество на конец месяца, умноженное на цену. Цена текущего месяца обновляется каждый день, а по его окончании фиксируется, поэтому рост курса виден в статистике как рост накоплений, а прошлые месяцы не меняются. Прошлые месяцы без цены заполняются настоящими данными: курсы Нацбанка РК и месячные цены закрытия Yahoo Finance. Если данных нет, берётся ближайшая более поздняя цена. Курсы (Нацбанк РК, все пары через тенге) и котировки (неофициальный адрес Yahoo Finance) обновляются при запуске и раз в сутки; в запросах уходят только тикеры. Если источник недоступен, остаются прошлые значения с их датой.

## Начисление участнику

Участника можно привязать к фонду в его настройках. С месяца включения сумма плана фонда сама записывается расходом, оплаченным участником: долг базы растёт, остаток фонда не копится. Запись следует за планом, пока месяц открыт, закрытые месяцы не меняются. Выключение снимает начисления открытых месяцев.

## Участники без аккаунта

Администратор может добавить участника без аккаунта: войти он не может, но на него записываются доходы, расходы и выплаты. Позже его можно связать с настоящим человеком по одноразовой ссылке или выбрать из уже вступивших. Вся его история в этой базе переходит к этому человеку, отменить связь нельзя.

## Удаление

Операции, выплаты, корректировки, участники и теги из базы не удаляются: запись получает отметку `inactive_at` с датой и временем в UTC и перестаёт показываться и участвовать в расчётах. Правка операции перезаписывает её, история правок не хранится.

## Доходы

Доход можно привязать к участнику базы, в форме и на экране проверки выписки. По умолчанию это тот, кто вносит операцию или загрузил выписку. На долги участников это не влияет. Раздел «Доходы» в статистике показывает суммы по месяцам и по людям.

## Темп трат

В текущем месяце на отметках 25%, 50% и 75% срока траты фонда сравниваются с такой же долей лимита. Если их больше, на экранах «Месяц» и «Статистика» появляется предупреждение и прогноз, когда кончится лимит. Учитываются траты до дня отметки, поэтому вывод держится до следующей отметки. Сохранённые в фонде остатки прошлых месяцев не учитываются. Галочка у фонда в «Ещё» → «Фонды» выключает проверку.

## Теги

Теги ставятся на расходы и возвраты и не влияют на суммы. Можно выбрать существующий или ввести свой.

- **Выписка:** тег берётся из истории продавца (если стоит хотя бы на половине его покупок). Если таких нет, теги предлагает Claude Haiku. На экране проверки их можно убрать или заменить.
- **Ручная операция:** подставляются теги прошлой операции с тем же комментарием, частые теги фонда показываются первыми.

В закрытом месяце теги, как и саму операцию, изменить нельзя.

## Локальный запуск

Нужен Node.js 22.13 или новее (используется встроенный `node:sqlite`).

```bash
npm install
```

```bash
npm run build
```

В `.env` укажи `DEV_AUTH=1` и `OWNER_TELEGRAM_IDS=1`, затем:

```bash
npm start
```

Приложение откроется на http://localhost:3000/?devUser=1. Другой номер в `devUser` означает другого пользователя: так можно проверить форму участника.

## Проверки

```bash
npm test
```

```bash
npm run typecheck
```

Тесты на настоящих выписках запускаются, только если заданы пути `KASPI_PDF` и `FREEDOM_PDF`. Сами выписки в репозиторий не добавляются.

## Запуск в Telegram

Нужны VPS на Debian или Ubuntu и домен, направленный на этот сервер. Вместо своего домена подойдёт адрес вида `1-2-3-4.sslip.io`. Если порт 443 занят, передай скрипту настройки другой порт вторым аргументом и укажи его в адресе Mini App.

1. Создай бота в @BotFather и включи Main Mini App: `/mybots` → бот → Bot Settings → Configure Mini App, адрес `https://твой-домен`. Там же настрой кнопку меню. Приглашения работают через Main Mini App.
2. Скопируй на сервер `deploy/setup-server.sh` и запусти его от root, указав домен. Скрипт установит Node.js и Caddy (он сам выпускает HTTPS-сертификат).
3. Заполни `/opt/monzoid/.env` на сервере: токен, имя бота, ключ Anthropic и `OWNER_TELEGRAM_IDS` (свой Telegram ID). Новые люди входят только по приглашению. Базу может создать владелец, участник какой-либо базы или человек с одноразовым приглашением в сервис («Ещё» → «Пригласить в сервис», кнопка есть только у владельца).
4. Со своего компьютера выполни `bash deploy/deploy.sh root@сервер`. Этой же командой выкладываются обновления.

Сервис работает с `NODE_ENV=production`, поэтому вход без Telegram отключён. База лежит в `/var/lib/monzoid`. Раз в сутки туда же, в `backups/`, сохраняется копия. Когда копии вместе превышают 128 МБ, удаляются самые старые. Эти копии остаются на том же сервере, так что время от времени скачивай их к себе.
